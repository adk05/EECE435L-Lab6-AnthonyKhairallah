# EECE 435L – Lab 6

## Features
The calculator implements seven operations:
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Exponentiation
- Square root

## Requirements
- Python 3.10
- PyBuilder

## Setup and Execution

1. Navigate to the calculator directory:
   ```bash
   cd calculator_Anthony_Khairallah
   ```

2. Create and activate a virtual environment:
   ```powershell
   py -3.10 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

3. Install PyBuilder:
   ```bash
   pip install pybuilder
   ```

4. Run the unit tests:
   ```bash
   pyb run_unit_tests
   ```

## Results
All 7 unit tests passed successfully using PyBuilder.
